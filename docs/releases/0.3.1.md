Fixes the Android app's updates.

**Fixed in 0.3.1**

- **Android updates install.** The app now opens Android's own installer on the checked APK. Before, the update could stall at the Play Protect check and never install.
- **Updates are reachable from every screen.** A card shows a new version before you connect, and the update notification opens it directly.
- **Real update notifications.** The phone checks the release page every six hours, even when 1loop is closed.

<!-- end of the in-app notes -->

**If your phone runs 0.2.0 or 0.3.0**, its built-in updater cannot install this version: download `1loop-0.3.1.apk` from the release page and open it once. Your chats and settings stay. Later updates install from the app.

**Install**

| Platform | File |
|---|---|
| Linux x86-64 | `1loop-0.3.1-linux-amd64.tar.gz`: extract, run `./1loop` |
| Windows 10 1809+ x64 | `1loop-0.3.1-windows-amd64.zip`: extract, run `1loop.exe` (or `1loop-software.cmd` without OpenGL) |
| Android 8+ | `1loop-0.3.1.apk`: open it on the phone |
| Server | `1loop-server-0.3.1-linux-amd64` or `…-windows-amd64.exe`: see docs/SERVER.md |

**Android warning:** Google Play Protect may say 1loop is harmful, or recommend a scan. 1loop is installed from outside the Play Store and can run a Debian environment, run commands and control the phone when you allow it. The code is open in this repository. Choose *Install anyway* or *Install without scanning*.

Windows SmartScreen may show *Windows protected your PC*: choose *More info → Run anyway*.

The full guide: docs/INSTALL.md in the repository.
