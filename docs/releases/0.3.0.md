The first public release of 1loop: a coding agent for your projects, with the models you choose, on Linux, Windows, Android and headless servers.

**New in 0.3.0**

- **Updates built in.** Desktop, phone and server check the release page and install new versions in a click, from signed downloads.
- **Your prompts are kept.** Each conversation keeps its own draft through crashes, restarts and chat switches, with undo and redo.
- **Switching models asks how.** A new provider, account or model receives the conversation as it is, or summarized by the model of your choice, with 1loop's recommendation.
- **Files tab** on the desktop, the remote desktop and the phone: browse the project, preview code and images, attach or add files. *Share → 1loop* on Android.
- **Copy project** between devices, with its conversations; later copies only send what changed, and nothing is lost when both sides changed.
- **The phone as a server**, Phone Use from paired devices, and more.
- Fixes: the phone returns to the end of a running chat after sleep; the task list no longer re-reads itself after every action nor grows across requests; its timers no longer reflow the tasks; the Android battery settings show consistent buttons.

**Install**

| Platform | File |
|---|---|
| Linux x86-64 | `1loop-0.3.0-linux-amd64.tar.gz`: extract, run `./1loop` |
| Windows 10 1809+ x64 | `1loop-0.3.0-windows-amd64.zip`: extract, run `1loop.exe` (or `1loop-software.cmd` without OpenGL) |
| Android 8+ | `1loop-0.3.0.apk`: open it on the phone |
| Server | `1loop-server-0.3.0-linux-amd64` or `…-windows-amd64.exe`: see docs/SERVER.md |

**Android warning:** Google Play Protect may say 1loop is harmful or block the install. 1loop is installed from outside the Play Store and can run a Debian environment, run commands and control the phone when you allow it. The code is open in this repository. Choose *Install anyway*.

Windows SmartScreen may show *Windows protected your PC*: choose *More info → Run anyway*.

The full guide: docs/INSTALL.md in the repository.
