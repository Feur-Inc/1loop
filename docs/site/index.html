Android may say 1loop is harmful. 1loop is installed from outside the Play Store and can run a Debian environment, run commands and control the phone when you allow it, which Google Play Protect treats as risky. Its code is open. To install it, choose Install anyway (or More details → Install anyway). Windows SmartScreen may also ask: choose More info → Run anyway.

Install

  1. Linux: tar -xzf 1loop-{{VERSION}}-linux-amd64.tar.gz -C ~/Applications/1loop, then run ~/Applications/1loop/1loop (install.sh beside it adds it to the applications menu). Keep the folder writable so updates can install. On Debian or Ubuntu: sudo apt install ./1loop-{{VERSION}}-amd64.deb.
  2. Windows: extract the zip to a folder you own and run 1loop.exe. Without an OpenGL driver, run 1loop-software.cmd.
  3. Android: open the APK on the phone and allow the install. Then pair with your desktop (QR code in Settings → Phone remote), add a server, or choose Local phone.
  4. Server: make the file executable and follow the server guide.

Updates

Installed apps check this page and offer new versions themselves: Settings → Updates. Every release is signed, and each download is checked before it is installed.
